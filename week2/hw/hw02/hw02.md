**GitHub REST API** 

5 endpoints tiêu biểu của GitHub API

| Endpoint (Mục đích) | Method | Status Codes Thường Gặp | Headers |
| :--- | :--- | :--- | :--- |
| `/users/{username}` | `GET` | **200 OK**<br>**404 Not Found**<br>| **Req:** `Accept`, `Authorization: Bearer`<br>**Res:** `ETag`, `Cache-Control` |
| `/user/repos` | `POST` | **201 Created**<br>**401 Unauthorized**<br>**422 Unprocessable** | **Req:** `Content-Type: application/json`, `Authorization`<br>**Res:** `Location: https://api.github.com/repos/...` |
| <br>`/repos/{owner}/{repo}` | `PATCH` | **200 OK**<br>**403 Forbidden** (không có quyền) | **Req:** `Content-Type`, `Authorization`<br>**Res:** `Content-Type: application/json` |
| <br>`/repos/{owner}/{repo}` | `DELETE` | **204 No Content**<br>**403 Forbidden** | **Req:** `Authorization: Bearer` |
| <br>`/repos/{...}/pulls` | `GET` | **200 OK** | **Req:** `Accept: application/vnd.github.v3+json`<br>**Res:** `Link: <.../pulls?page=2>; rel="next"` |
